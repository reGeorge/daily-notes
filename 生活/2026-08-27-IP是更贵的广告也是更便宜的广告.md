# IP 是更贵的广告，也是更便宜的广告

## 观察

> 最近突然想明白一件事：
>
> 泡泡玛特卖的可能根本不只是盲盒，而是未来的广告位。
>
> 传统广告的逻辑是买注意力。
>
> 品牌花钱把一个东西塞到你眼前：
> “看我。”
> “记住我。”
> “买我。”
>
> 但 IP 不一样。
>
> 一个 IP 如果足够可爱、足够稳定，先让你买一个放在桌子上。
>
> 然后它陪你一年、两年、五年。
>
> 搬家带着它。
>
> 换工作带着它。
>
> 甚至失恋、失业、经历生离死别的时候，它还在那里瞅着你。
>
> 这时候，大脑会发生一件很奇怪的事情：
>
> 它开始给这个东西自动加光环。
>
> 你喜欢的已经不是那个几十块、几百块的玩偶了。
>
> 它开始变成某段人生的记忆。
>
> 我突然想到自己养了 12 年的巴西龟“大乔”。
>
> 它其实什么都没做。
>
> 不会聊天，不会安慰我，也不会在我难过的时候给我情绪价值。
>
> 但它陪了我 12 年。
>
> 所以现在再看它，它已经不是一只乌龟了。
>
> 它更像一个时间的锚点。
>
> 小时候暑假反复看的《西游记》也是一样。
>
> 我们明明知道剧情，甚至知道下一句台词，但多年以后重新听到片头曲，还是会莫名其妙地产生一种感觉。
>
> 这种喜欢甚至不需要解释。
>
> 这可能就是 IP 最可怕的地方。
>
> 它不是一次性买你的注意力。
>
> 而是慢慢进入你的生活，最后进入你的记忆。
>
> 于是商业模式就变了：
>
> 盲盒只是第一次交易。
>
> 毛绒、挂件、手机壳、联名、游戏、线下体验……都是后面的交易。
>
> IP 越成熟，品牌每推出一个新东西，就越像是在自己的用户心智里重新投放一次广告。
>
> 所以我现在越来越觉得：
>
> IP 是一种更强大的广告和流量。
>
> 传统广告需要不断购买注意力。
>
> IP 的终极状态，是让用户主动给它留一个位置。
>
> 甚至可以把它理解成：
>
> IP = 用户心智里的永久货架。
>
> 而真正值钱的，从来不是货架上现在摆着什么。
>
> 而是：
>
> 这个货架，未来还能摆多少东西。
>
> 这可能也是为什么，真正伟大的消费品牌最后卖的都不只是产品。
>
> 它们卖的是一种：
>
> “我不知道为什么喜欢，但它一直在那里。”
>
> 时间，才是最贵的情绪价值。
